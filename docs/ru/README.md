## С чего начать

Выберите маршрут в зависимости от своей цели:

- **Что работает в текущем репозитории?** Сначала прочитайте корневой раздел
  [о статусе проекта](../../README.ru.md#статус), затем используйте подробное
  [текущее состояние реализации](../../spec/current-state.md), где разделены
  реализованные, изолированные, запланированные и отсутствующие возможности.
- **Что входит в опубликованный релиз?** Прочитайте
  [заметки к релизу `v0.1.0-alpha`](releases/v0.1.0-alpha.md). Опубликованный
  alpha-релиз — более ранний срез, чем текущее состояние репозитория.
- **Хотите участвовать в разработке или следить за её направлением?** Начните
  с корневого раздела [об участии в разработке](../../README.ru.md#участие-в-разработке),
  затем используйте [Инженерный план развития](roadmap/README.md) и
  [Инженерную Wiki](../../wiki/README.md) для планов, принципов, процесса и
  границ ответственности за знания.

Текущая веха **Beta — Complete the Single-Node Runtime** описывает инженерный
прогресс, а не готовность к production-эксплуатации. Production-инструкция по
установке и работе оператора пока отсутствует: Control Service Production
Activation и полный operator workflow не реализованы. Используйте текущее
состояние для фактов о репозитории, а заметки к релизу — для фактов о
опубликованной версии.
