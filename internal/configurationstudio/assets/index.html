Local Configuration Studio

Create a configuration or Draft, or edit an existing Draft listener using the Control Service API. Use this studio only in a trusted local development environment.

Before you continue

  • Published does not mean Running. This studio does not start or manage a Runtime.
  • Control Service data is stored only in memory and is lost after the Control Service restarts.
  • Any WebSocket URL shown here is preliminary. It is not a reachability or Runtime-status check.
